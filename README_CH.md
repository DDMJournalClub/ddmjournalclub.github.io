## 📖 关于 DDMJC

DDMJC (Diffusion Decision Model Journal Club) 是一个由 **漂移扩散模型 (DDM)** 兴趣小组发起的线上文献分享与交流活动。

我们致力于通过线上方式与国内外学生和同行交流学习 DDM 及相关模型。活动主要关注：

- 🧠 **扩散决策模型的基础知识及相关研究**
- 📊 **DDM 在决策任务中的应用、代码实现及数学原理**
- 💻 **认知建模和心理学方法的相关讨论**
